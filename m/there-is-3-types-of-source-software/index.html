☆======= There is 3 types of source software =======☆

For me there is 3 types of source software Not just the 2 classics..
- Closed-Source / Proprietary
  • Corporate or just user preference in keeping the code locked away from the user.
  • You own nothing, just use whatever they (creators) provide you.
! Examples: Microsoft cloud products, windows OS, whatsapp, most android apps and some others..
- Open-Source
  • Open code, anyone can just.. see the code, and do whatever with it (depends on what the license of the project says).
  • Managed by the community, anyone can contribute to make the project better.
  • Usually provides tools for the user to compile the project on it's own.
! Examples: Blender, OBS Studio, signal and more...
- Free software
This is a compleatly different category, one that goes beyond any other.
  • Consists in pure freedom, the code is yours, the right is yours, the project is yours and anyone's.
  • Do whatever you want, without limits or anyone to stop you from doing what you wish do to.
  • No one owns this, it belongs to the world now.
  • This is the rarest type, creators are often scared of giving total freedom to users.
Basicly anarchy, but in a good way, the world needs more of this, and less of the other 2 types. Can be considered a selfless act, but it's not, it's a win-win for everyone, the creator gets to share their work with the world, and the users get to enjoy it without any limits or restrictions.
